# Splat Suite — update feed

This public repo holds **only a version pointer** (`latest.json`) so the Splat
Suite app can tell you when a new release is out. **No source code lives here.**

The app source and the downloadable releases are in a private repo; only
invited collaborators can download them. The `url` field is informational —
the app always opens its own fixed releases page, never a link from this file.
